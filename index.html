Подключение Spotify

Нужен только Client ID собственного Spotify-приложения. Client Secret вводить не нужно.

Redirect URI для настроек Spotify
Как получить Client ID?
  1. Открой Spotify Developer Dashboard ↗ под Premium-аккаунтом.
  2. Нажми Create app (если ещё нет приложения).
  3. В Redirect URIs добавь адрес из блока выше точно, без изменений.
  4. Выбери Web API, если Spotify предложит выбрать API.
  5. Скопируй Client ID сюда. В User Management добавь свой Spotify-аккаунт, если требуется.
